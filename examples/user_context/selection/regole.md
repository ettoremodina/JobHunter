# Regole di revisione

Regole confermate dall'utente. L'agente le applica agli annunci indecisi di Jev e ai ruoli compatibili di Tier A/B, e ogni suo verdetto ne cita almeno una.
Modificare o cancellare una regola fa scadere i verdetti che la citano.

Review rules you confirm in chat. The review agent appends them here, each one under its own marker and ID (R1, R2…); you can edit or delete them by hand. The file starts empty.
