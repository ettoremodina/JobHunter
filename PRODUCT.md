# JobHunter

## Platform

Local web dashboard and Python CLI on the user's PC. Codex is the primary conversational interface.

## Users and purpose

A single user collects broad job data, selects companies and manually verifies interesting opportunities. Targeted research complements bulk collection. One company appears once, with its opportunities inside the detail.

## Confirmed constraints

Readable, navigable functionality takes priority over decoration. Analysis happens in Codex chat; no mandatory local or cloud LLM. Persist decisions between sessions. Keep original user notes and datasets. inClimate is suspended because the user reports a paywall.

## Core workflow

Collect or import, normalize, group companies, search and compare, open sources, save or discard with explicit scope, and undo decisions. Source failures and data age must be visible.
